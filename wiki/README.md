# MAX API Wiki v1.0.0 · API v1.11.0

Интерактивная русскоязычная документация с локальной Three.js 0.180.0.
Без CDN, без ввода API-ключей и без отправки запросов к MAX из wiki.

В основном архиве wiki запускается вместе с API: из корня max-userbot выполните
`docker compose up -d --build`. API — на 8087, wiki — на 8088.
Откройте http://127.0.0.1:8088. Для сервера задайте WIKI_BIND_HOST=0.0.0.0
в корневом .env и пересоздайте wiki; адрес станет http://IP_СЕРВЕРА:8088.
Альтернатива: `ssh -L 8088:127.0.0.1:8088 user@server`.
Сервис документации не получает ключи и базы аккаунтов.

Для отдельного запуска только документации из этой папки:
`docker compose up -d --build`. Не запускайте одновременно два wiki-контейнера
на одном порту 8088. Локальный запуск без Docker тоже возможен:
`python3 -m http.server 8088 --bind 127.0.0.1`.

Главная — index.html; текстовая версия — WIKI.md.
examples/client.py — Python-клиент без внешних зависимостей.
examples/bot.py — бот команд; запуск и ограничения описаны в wiki.
deploy/ — пример HTTPS reverse proxy для существующего проекта API.
openapi.json — схема tenant API; admin-openapi.json — отдельная админская схема.

Проверьте WIKI.md перед запуском примеров: они способны отправлять сообщения.
Версия wiki независима от версии сервера. Этот архив не обновляет сервер API.

Перед запуском интеграции скопируйте examples вне каталога wiki. Не храните рабочие bot.env, QR и базы данных в опубликованном каталоге сайта.
