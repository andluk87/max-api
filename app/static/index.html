Очередь и результаты

Входящие сообщения

Все доступные чаты MAX и их история. Выберите чат; для новых сообщений нажмите «Обновить».

Выберите чат слева.

Автоматические пересылки

Все новые сообщения из выбранных чатов отправляются в выбранном режиме. Перепосты и повторные сообщения пропускаются. История до включения не пересылается.

Откуда брать новые сообщения

Выключение отменяет ожидающие отправки. Уже начатая отправка может завершиться. Браузер можно закрыть — правило работает на сервере.

Последние отправки

Диагностический журнал

Последние 5000 записей текущего аккаунта. Время показано для Анадыря. Успешные фоновые GET-запросы не записываются.

Управление пользователями

У каждого пользователя свой аккаунт MAX и отдельные сообщения, расписания и пересылки. «Открыть панель» даёт администратору доступ ко всем операциям выбранного аккаунта.

Сохраните ключ сейчас: повторно показать его нельзя. При замене прежний ключ перестаёт работать.
